# 中文字词库意图识别和抽槽系统

这是一个基于FastText和Qwen模型的中文字词库意图识别和抽槽系统，能够自动识别用户查询的意图并提取相关槽位信息。

## 功能特性

### 1. 意图识别
- **快速分类**: 使用FastText模型进行快速意图分类
- **二次检验**: 使用Qwen模型进行意图验证和优化
- **支持意图类型**: 读音、书写、查字、查词、组词、释义、分字
- **其他类别处理**: 自动识别非字词库相关查询并进行联网搜索

### 2. 抽槽功能
- **槽位提取**: 自动提取查询中的关键信息
- **复合意图处理**: 支持复杂查询的分解和处理
- **多种槽位类型**: 支持字符、词组、笔画数、结构类型等多种槽位

### 3. 搜索功能
- **联网搜索**: 对"其他"类别查询提供搜索支持
- **多搜索引擎**: 支持百度、必应、谷歌等搜索引擎
- **智能回答**: 基于搜索结果生成相关回答

## 支持的查询示例

### 字词库相关查询
- **读音**: "焜字怎么读？"
- **书写**: "焜字怎么写？"
- **查字**: "艮字加三笔是什么字？" / "左边一个木，右边一个黄是什么字？"
- **查词**: "毛泽东的字是什么？"
- **组词**: "用好字组词"
- **释义**: "好字是什么意思？"
- **分字**: "伟字的左边是什么？"
- **复合查询**: "伟字的左边加上沐的右边是什么字？"

### 其他类别查询
- **天气**: "合肥明天会下雨吗？"
- **新闻**: "帮我搜一下最新的AI进展"
- **股票**: "今天A股行情如何？"

## 槽位定义

| 槽位名称 | 类型 | 描述 | 示例 |
|---------|------|------|------|
| target_char | list | 单个目标字 | ["焜"] |
| target_phrase | list | 单个目标词 | ["毛泽东"] |
| strokes | int | 笔画数变化 | 3, -1 |
| radical | str | 偏旁/部首 | "提手旁" |
| structure_type | str | 汉字结构 | "left_right" |
| component_count | int | 部件数量 | 2 |
| components | list | 具体部件 | ["木", "黄"] |
| target_component | list | 目标部件位置 | ["左"] |

## 配置说明

### 模型配置
在 `config.py` 中可以配置：
- FastText模型路径
- Qwen模型名称
- 设备选择（CPU/GPU）

### 搜索API配置
在 `search_handler.py` 中可以配置：
- Bing搜索API密钥
- Google搜索API密钥

## 注意事项

1. **模型依赖**: 首次运行时会自动下载Qwen模型，需要网络连接
2. **FastText训练**: 如果没有预训练的FastText模型，系统会自动创建训练数据并训练
3. **搜索功能**: 联网搜索功能需要网络连接，可能受到网络环境影响
4. **GPU支持**: 系统会自动检测GPU可用性，推荐使用GPU加速

## 扩展功能

### 添加新的意图类型
1. 在 `config.py` 中的 `INTENT_TYPES` 添加新类型
2. 在 `intent_classifier.py` 中添加训练数据
3. 在 `slot_extractor.py` 中添加对应的抽槽逻辑

### 添加新的槽位
1. 在 `config.py` 中的 `SLOT_SCHEMA` 添加新槽位定义
2. 在 `slot_extractor.py` 中实现提取逻辑

## 性能优化

1. **模型量化**: 可以使用量化版本的Qwen模型减少内存使用
2. **缓存机制**: 可以添加结果缓存提高响应速度
3. **并行处理**: 可以实现批量查询的并行处理

## 故障排除

### 常见问题
1. **模型加载失败**: 检查网络连接和磁盘空间
2. **依赖包问题**: 确保安装了所有required依赖
3. **搜索失败**: 检查网络连接或配置API密钥
